## 在 UTAU 里实测得到的教训

这是整个项目里最值得记的一课：**数字自洽 ≠ 引擎能放**。

`oto.py` 从第一版起就把右边界写成 `-55`。我用真实声库做统计检验时，
为了"稳健"取了 `abs(cutoff)`，结果成立率 100%，于是得出「UTAU 按绝对值处理、
符号无所谓」的结论。**那个结论是错的** —— `abs()` 恰好把要检验的那个维度
抹掉了，正负两派写法都能通过检验，检验本身没有分辨力。

真实规则是**符号改变含义**：

| 符号 | 含义 |
|---|---|
| 正值 | 距**文件末尾**的距离 |
| 负值 | 从 **offset 起算的长度** |

于是 `-55` 被理解成「可用区只有 55ms 长」，除纯元音外（固定区 40ms）全部采样
被整个吃掉。症状是 **UTAU 里只有 `a` 有声音**，`ba`/`ka`/`pa` 等全部静音。

改成正值 `+55` 后解决。**教训：统计检验要挑有分辨力的量；`abs()`、`max()` 这类
"稳健化"操作会无声地抹掉正在考察的维度。**

## 声带源：反馈 FM

纲领 三.1 写的是两算子 FM `y = sin(2πk·f0·t + I·sin(2πf0·t))`。实测发现
**这个结构无法产生平滑的声源谱**：J_n(I) 在低次谐波区有周期约 4 条谐波的深谷，
对载波 k 求和相当于滑动平均，而滑动平均的传递函数必有零点 —— 权重只能挪动
零点、填不平。试过的补救全部无效：多对齐奏平均（σ 收敛在 5.7 dB）、多调制器、
串联两算子 FM、动态调制指数。

后果不只是音色问题：声源有 15 dB 深谷时，落进谷里的共振峰会失去定义；
而且零点按**谐波序数**排列，换音阶时会在频率轴上移动，导致音阶间音色漂移。

改用**反馈 FM**：

```
y[n] = sin(φ[n] + β·y[n-1]),   φ[n] = ∫2πf0(t)dt
```

β→1 时谱形趋近锯齿波的 1/n 衰减，谐波列平滑无梳齿 —— 这正是纲领
「用纯正弦运算产生谐波列，替代锯齿波声带源」想要的结果，β≈0.95 时实测梳齿
σ=0.8 dB。代价：递归式无闭式解、边带无限延伸，必须 4× 过采样 + 抗混叠降采样
（44.1kHz 直出会有约 -23 dB 非谐波残余）。

三条候选方案的对照样本保留在 `demo/` 下。

## 音色设定

**女性化：共振峰整体 ×1.22**（`FORMANT_SCALE`）。声学上女声共振峰比男声高
15~20%，这个比例是「听上去像不像女声」的关键参数，改它比改别处都有效。
带宽按 ×1.10 放大（不跟着等比例放大，否则高频共振峰会过宽而糊掉）。

### 基准音高：为什么改成 D#4

UTAU 声库必须选一个「原音音阶」（录制基频），引擎靠重采样把它变到任意音高。
这个值**没有标准**，各声库自己定：

| 声库 | 实测基频 | 折算音名 |
|---|---|---|
| 重音テト 単独音 | 308~313 Hz | **D#4** |
| Hitsuboku Kumi（`A4` 文件夹）| 588 Hz | D5 |

（Kumi 那个文件夹明明叫 `A4`，实际录的却是 D5 —— 文件夹名不可信，要测量。）

原先我们按 C4（261.6Hz）渲染，比 Teto 低三个半音。这在**直接对比原始 wav**
时会系统性地显得更闷：实测同样参数下，C4→D#4 让 /a/ 的 4~6kHz 提高约 8dB、
6~10kHz 提高约 6dB，质心从 1006 升到 1024。所以基准音高本身是这 20dB 缺口里
真实存在的 8dB。

选择音高的实际考量是重采样距离：录在常用音区的中间，往高往低都少失真。
女声 CV 声库常见 C4~E4，Teto 取 D#4。**当前基准音高 = D#4**（`build.py` 的 `PITCHES`）。

### 「沉闷」的真正位置在 4kHz 以上，不在 1~3kHz

这是整个音色调试里最绕的一段。逐频带测量（相对本文件谱峰，dB）才看清：

| | 0-700 | 700-1500 | 1500-2500 | 2500-4000 | 4000-6000 | 6000-10k | 10k-20k |
|---|---|---|---|---|---|---|---|
| Teto `/a/` | -9.0 | 5.4 | -6.7 | -27.2 | -16.4 | -28.7 | -32.7 |
| 旧版 `/a/` | -8.8 | -0.3 | 2.0 | -13.4 | **-37.6** | **-48.5** | **-51.3** |
| Teto `/i/` | 2.8 | -19.4 | -27.3 | -9.3 | -4.1 | -19.9 | -24.8 |
| 旧版 `/i/` | 2.0 | -31.0 | -22.0 | -8.2 | **-24.6** | **-43.9** | **-51.3** |

结论正好相反于直觉：**1~3kHz 我们并不缺，4kHz 以上才全线低 19~26dB**，
而 2.5~4kHz 我们反而高 14dB。之前把力气都花在 1~3kHz（`PEAK_DB=+12 @2.2k`），
那只是在最刺耳的频段堆能量 —— 于是「高频很吵」和「依然沉闷」同时出现。

### 为什么这是个结构问题

5 级串联谐振器在最高共振峰以上是 60dB/oct 的陡降，4kHz 以上不可能有能量。
而真实录音在那里的能量主要来自**呼吸噪声与房间声**，本来就不走声道。
所以要绕过串联滤波器，分两条路补：

| 路径 | 来源 | 听感 |
|---|---|---|
| 谐波空气 `HARM_AIR_*` | 声源高通 4kHz / 4 阶后直接叠加 | 光泽、金属感 |
| 噪声空气 `AIR_*` | 白噪高通 4kHz + 低通 12kHz | 空气、气息 |

只放噪声会听成嘶声，只放谐波又会发干。**两条都要带上限**：谐波空气只放到
6.5kHz（4~6kHz 是「光泽」，再往上就是刺耳），噪声空气放到 12kHz（「空气」需要
一直延伸到听觉上限）。配比 `0.06 / 0.013`。

在 D#4 下与 Teto `/a/` 的逐频带对照：

| | 2.5-4k | 4-6k | 6-10k | 10-20k |
|---|---|---|---|---|
| Teto | -27.2 | -16.4 | -28.7 | -32.7 |
| 本声库 | -22.6 | -19.5 | -28.6 | -36.1 |

四个频带都在 4.6dB 以内。

### `/i/` 的 F1 要故意放宽

D#4 的基频 311Hz 正好落在 `/i/` 的 F1（约 366Hz）带内，窄 F1 会让 h1 独吞全部
共振增益：实测 **h2 比 h1 低 27dB，参考只有 12dB**，整个 F2 区被压暗。
把 F1 从 290 抬到 300、带宽从 60 放宽到 120（比 F2 的 100 还宽），h2 抬高约 10dB：

| | 700-1500 | 1500-2500 | 2500-4000 |
|---|---|---|---|
| 原 F1=290/60 | -37.5 | -34.9 | -20.7 |
| 现 F1=300/120 | -32.6 | -32.3 | -17.7 |

再宽就听不出是 `/i/` 了（F1=310/190 已试，辨识度下降）。

**注意不要按 Teto 的 `/i/` 去追 4~6kHz**：她那个样本的 4~6kHz 只比基频低 4dB，
比她自己的 `/a/` 高 12dB —— 那是录音气声偏重，不是元音特征。

`PEAK_FC/DB = 3000/-8` 负责压掉 2.5~4kHz 的多余能量
（Teto 在这里有一个明显的谷，比它自己的 4~6kHz 还低 11dB —— 这个「先谷再峰」
的谱形才是「明亮但不刺耳」的关键）。

### 试过但不成立的路：并联共振峰

一度怀疑串联结构本身有问题，换成并联（每个共振峰独立谐振、按 A 加权求和），
`phonemes.py` 里因此有 `A` 字段和 `dsp.formant_parallel`。

**这是错的**，但错得很有信息量。并联里每个谐振器的直流增益都是 1，五个加起来
就是 ΣA ≈ 3 的低频堆积（+9.6dB）；串联的直流增益恰好是 1。结果是并联的谱质心
只有 500~860Hz，比串联（1047）还低，**更沉闷**。

补救都试过：物理幅度 `A_i ∝ 1/F_i`、事后高通补偿、对数域最小二乘拟合
（拟合直接把 A3/A4 压到 0，残差 4.9/7.2dB —— 说明不是幅度问题，是位置不匹配）。
根子在于：要让并联的共振峰和串联一样突出，A_i 必须远大于 1，但那样低频会涨得更多；
换成带通谐振器能消掉直流，可基频（262Hz）又会被衰减 20dB。**串联才是对的**，
Klatt 合成器用串联正是这个原因。

顺带一个测量教训：早先用 k=6 的滑动平均平滑谐波包络（f0=310 时相当于 ±1850Hz），
把共振峰整个抹平了，据此得出的「2.8k/5.5k 有凹陷」是假象。**平滑窗不能宽过要
观察的结构。**

## 人性化

声音「僵硬单一」有三个来源，分别处理（强度档位：轻微）：

| 问题 | 手段 | 参数 |
|---|---|---|
| 音高是死的 | jitter：周期到周期的微小音高扰动 | `JITTER_STD` = 0.3% |
| 音量是平的 | shimmer（快）+ 自然渐弱渐强（慢） | 4% + 5% |
| 音色不动 | 每个共振峰独立缓慢游走 | `FORMANT_DRIFT` = 0.8% |
| 每个采样雷同 | 每个音素用独立随机种子 | 固定 `PHASE_SEED` 保证可复现 |

**没有烘入颤音**。颤音是 4~6Hz 的周期性起伏，UTAU 编辑器本来就会自己加；
烘进采样会与之双重叠加，且采样被变调到别的音高时颤音速率也会跟着变。
jitter 是另一回事 —— 它是 3.5ms 相关长度的随机扰动，不构成颤音。

需要看「没有人性化」的干净版本时传 `humanize=False`（频谱测量与 oto 调参要用）。

## 辅音处理

### 软腭音的 locus 必须随元音变

软腭是协同发音最强的部位。如果给 /g/ /k/ 一个固定的高 F2 locus（比如 1900Hz），
会出现两个问题：

- **/gu/ 听起来像 /du/** —— 软腭与齿龈的 locus F2（1900 vs 1700）太接近。
  真正的区分线索是 F2 的**移动幅度**：/gu/ 的 F2 几乎不动（1050→760），
  而 /du/ 要从 1700 掉到 760。
- **/ko/ 听起来像 /kio/** —— F2 从 1900 扫到 850 会途经 ~1400 的 /e/ 频段，
  听起来就多出一个介音。

现在 `VELAR_LOCUS` 逐元音给出 locus，实测轨迹：gu 1100→900，du 1700→900，
ko 1300→1000。

### 爆破拆成两部分

爆破噪声原来只走部位带通、绕开声道滤波器 —— 它是唯一没被声道塑形的成分，
听上去像贴上去的咔哒声。现在拆成：

- **经声道的一份**（`GAIN_BURST_TRACT`）：带上 locus 的共振峰色，融进后面的音
- **走部位带通的一份**（`GAIN_BURST`）：保留 g/k 与 d/t 的区分线索
  （齿龈爆破在 3kHz 以上，软腭爆破是 1.3~2.9kHz 的紧凑一团）

包络也从对称驼峰改成 1.5ms 快起 + 指数衰减 —— 对称驼峰的峰值落在正中间，
听起来是一声闷响而不是爆破。

### 爆破的高频要压住

爆破最初听起来像白噪声嘶声。两个来源：

1. **齿龈爆破频段给得太高**（3k~5.5k）。真实的齿龈爆破峰值在 2.5~4kHz 并向上
   滚降，取到 5.5k 就成了嘶声。现在收到 1.8~3.2k。
2. **给女声加亮的 F5（4880Hz）在给爆破噪声加料**。宽带噪声过这条高 Q 谐振器
   会被抬得很亮。所以爆破的经声道那一路单独走一条 2.7kHz / 4 阶低通
   （`BURST_LP`），而送气、/h/、气声不受影响。
3. **带通只要 2 阶的话，裙边会一直延伸到 4~6kHz**，那正是"嘶"的频段。
   爆破带通改成 4 阶。

改进前后（4~10kHz 能量占比，元音稳态自身约 -30dB）：

| 音节 | 质心 | 4~10kHz |
|---|---|---|
| ta | 3124 → 1859 Hz | -3.4 → -30.8 dB |
| da | 3507 → 2086 Hz | -3.7 → -28.9 dB |
| ka | 1830 → 1254 Hz | -15.3 → -43.7 dB |
| ga | 2075 → 1354 Hz | -17.8 → -43.4 dB |

三个部位仍分得很开（pa 925 / ka 1254 / ta 1859 Hz），齿龈音依然最亮 —— 这符合
真实语音。

### 释放段必须是一条连续包络

最初起爆和送气是两段、各带一次起音，结果是：起爆衰减到零 → 送气从零重新起音。
听感上就是两个独立事件（先一下闷响、再一阵嘶声）。更早的版本里送气还被调得比
起爆响 16 dB，于是整个释放段变成「静音后突然一阵嘶声」——「突兀」的真正来源。

现在起爆与送气**共用一条包络**（`_release_env`）和**一个总增益**（`GAIN_RELEASE`）：

    1.2ms 快起 → 约 6ms 内衰减到平台电平 RELEASE_PLATEAU
                → 送气从该电平接着缓慢衰减
                → 最后溢出 RELEASE_SPILL 毫秒，与浊音起始交叉淡化

关键细节：`RELEASE_TAIL` 必须让送气在段末**保留**住电平（0.55），把剩余的衰减
交给溢出段去做。如果让送气在自己段内就衰减到 0（原来取 0.15），那么溢出段开始时
已经没有东西可交叉了，坑依然存在。

### 噪声→浊音的交界都要交叉淡化

同样的问题出现在擦音上：`sa` 的擦音衰减到 0.01，然后浊音从 0 慢慢爬升，中间是断的。
现在擦音也带 `FF_SPILL`（45ms）溢出，`sa` 的实测走势从
`0.14 → 0.01 → 慢爬升` 变成 `0.14 → 0.12, 0.15, 0.17, 0.19, 0.23 → 0.31`。

**这里踩过一个坑**：给擦音加溢出之后，交界处仍然有一个凹口。原因是 `flat` 形状
在段末做了淡出（`e[n-f:n] *= ...`），而溢出段又从 1 重新开始 —— 包络先降到 0
再跳回 1。有溢出段时必须撤掉段末淡出，把收尾整个交给溢出段。

### 起音不能太陡

擦音的起音最初只有 8ms，听感上是「突然出现」。擦音是舌头逐渐逼近成阻位置的
过程，起音应该慢一些，现在取 `FRIC_ON_RAMP = 35ms`。

塞音释放段的起音也从 1.2ms 放到 5ms（`RELEASE_ATTACK_MS`）。

### /s/ 不能用窄带通做，而且谱的目标要查文献

用窄带通（哪怕 4 阶）滤白噪，得到的是「哨音 / 静电噪声」的听感 —— 带限白噪的
谱太平、太窄，没有真实咝音的峰谷结构。真实 /s/ 是前腔几个宽共振叠加出来的，
所以改用 `dsp.sibilant`：陡峭高通串几个宽共振。

**关键是目标值不能凭感觉定。** 文献（PMC4457315，*Toward improved spectral
measures of /s/*）总结成人 /s/：

> 最低的谱峰在 **3.5–5 kHz**，大部分声能集中在 **4 kHz 以上**。

按本声库的女声 ×1.22 折算，最低峰应落在 4.3–6.1 kHz。最初把高通放在 3.9kHz、
共振峰放在 5.4/7.5/9.6k，能量重心跑到 6–8kHz，整体偏高一大截 —— 这就是
「像哨音」的来源。现在：

| | 值 |
|---|---|
| `SIB_HP` | 3400 Hz / 4 阶 |
| `SIB_PEAKS` | 4.8k / 6.8k / 8.8k（带宽 1.6k / 1.8k / 2.2k）|
| 谱重心 | 6303 Hz |
| 擦音/元音 | −14.4 dB |

`SIB_ROUGH`（22%）是慢速幅度起伏 —— 湍流噪声不是恒定电平的，完全平直的段
会听成「静电噪声」。

**`FF_SPILL` 不能太长**：原来 45ms 意味着 /s/ 要用 45ms 才淡出，那么长的一段
渐弱压在元音起始上，听感成了「气音尾巴」而不是咝音该有的收尾。现在 22ms。

四组候选方案留在 `demo/s_variants/`（由 `s_variants.py` 重渲），最终选定 V1。

### 过渡段不要排成串行

塞音原来是「闭塞 → 释放 → 送气 → 过渡」四段串行，`/ta/` 到元音要 175ms。
真实语音里共振峰过渡是**在送气期间同时发生**的，不该再往后加。
`GLIDE` 已从 45ms 收到 32ms。

### 送气不能比起爆轻太多

`RELEASE_PLATEAU` 原来取 0.45，送气段实测只有元音峰值的 -20dB、比起爆低 11dB ——
听感上是「起爆之后有一段空白，然后元音才出来」，这才是 /t/ 突兀的真正原因。

现在取 0.75，实测（相对元音峰值）：

| | 起爆 | 送气 | 落差 |
|---|---|---|---|
| ta | -9.4 dB | -13.4 dB | 4.0 dB |
| ka | -11.3 dB | -13.3 dB | 2.0 dB |
| pa | -12.0 dB | -13.9 dB | 1.8 dB |

起爆只比送气高 2~4dB，这是真实塞音该有的样子（原来 11dB 的落差是「空白」的来源）。

### 齿龈音的 locus 也要随元音变

`PLACE_LOCUS` 里齿龈给的固定 F2 = 1700，经 `FORMANT_SCALE ×1.22` 后是 **2074Hz** ——
已经落在 /e/~/i/ 的区间。于是 F2 从 2074 扫向 /u/ 的 927 时，起点就带着「前」的
音色，听起来多一个介音（`to` 像 `tio`、`tu` 像 `tiu`）。

这和当初 `/ko/` 听成 `/kio/` 是同一个病，只是当时只修了软腭。现在 `ALVEOLAR_LOCUS`
也逐元音给 locus，由 `PLACE_LOCUS_BY_VOWEL` 统一查表：

| | locus F2 → 元音 F2 | 移动量 |
|---|---|---|
| tu | 1403 → 927 | 476 Hz（原 1147 Hz）|
| to | 1525 → 1037 | 488 Hz |
| ko | 1342 → 1037 | 305 Hz |

### /s/ 的频段

带宽 4~8kHz、2 阶巴特沃斯时，低裙边在 2~3kHz 有可听能量，那正是 /ʃ/（sh）的
频段，所以 /s/ 听起来像 sh。现在改成 4.9~9.6kHz、4 阶，并把时长从 115ms 收到
80ms。实测擦音段里 5~10kHz 比 2~4kHz 高 7.5 dB（对照 /h/ 是低 40 dB）。

## 一条容易踩的坑：噪声路径的归一化

经声道的那条噪声（送气、气声、爆破的经声道成分）有两个陷阱，都会让实际电平
远低于标称值：

1. **宽带噪声过窄带谐振器后，输出电平比谐波声源低约 19 dB**，所以要先用单位
   白噪探一次这条路径再定标。
2. 定标之后还有两个次级效应：
   - 要是**先套包络再滤波**，短促的爆破（20ms）和送气（55ms）来不及让谐振器
     建立（BW=80Hz 要 12ms），输出再低 12~15 dB，而且损失随段落变化。所以改成
     **先滤波、再套包络**。
   - 就算先滤波，**按整段 RMS 归一化仍然不行**：同一条谐振器在元音区的宽带增益
     比在辅音 locus 区高约 5 倍，送气段实际只有标称的 1/5。所以改成按**逐点**
     局部 RMS 归一化（`dsp.local_rms`）。

改完之后 `GAIN_*` 才严格等于「相对浊音段 RMS 的电平」，可以直接按
`20·log10(值)` 换算。当前定标实测：/pa/ 送气 -13dB、/sa/ 擦音 -8dB、/ha/ -10dB。

**注意 GAIN 与峰值的关系**：爆破是静音之后的瞬态尖峰，听觉上比同等电平的
稳态信号突出得多。所以爆破的 GAIN 定得比稳态噪声低很多 —— 现在爆破峰值
比元音峰值低 18~24 dB，而送气的 RMS 只低 13 dB。

## 英语声库（Delta 式 CVVC）

```bash
python build_english.py            # 输出 out/chixian-en/，784 采样 / 1552 条 oto
```

英语用 **Delta 式英语 CVVC**（UTAU 英语的事实标准），别名是 X-SAMPA：

```
元音   i I E { A O V U u @ 3
双元音 aI eI aU OI oU
辅音   p b t d k g f v T D s z S Z h tS dZ m n N l r w j
```

四种别名形态，本批只做前两种 + 后两种的同形别名（Delta 第 6、7 号表的做法）：

| 形态 | 别名 | 用途 |
|---|---|---|
| `CV` | `p a` | 词中 |
| `- CV` | `- p a` | 词首 |
| `V C` | `a p` | 词中收尾 |
| `V C-` | `a p-` | 词尾 |

`- CV` 与 `V C-` **不是独立采样**，只是同一份 wav 的第二个别名 —— 两者的差别
本来就在 oto 参数里，不在波形里。辅音丛（`C C` / `C C-`）留到第二批。

### Windows 文件名不区分大小写

X-SAMPA 别名区分大小写，**Windows 文件名不区分**。直接用别名当文件名时，
`S.wav`/`s.wav`、`T.wav`/`t.wav`、`I.wav`/`i.wav`、`U.wav`/`u.wav` 会互相覆盖 ——
实测 784 个采样只落盘 545 个，而且 oto 里存在**指向错误音频**的条目（不报错，
只是悄悄听错）。现在文件名统一走 `build_english.SAFE` 的小写互异记号
（`I→ih`、`S→sh`、`dZ→jh`、`aI→ay`…），**别名仍是 X-SAMPA**。

### 英语比中文多出来的三类音

| 类型 | 处理 |
|---|---|
| 双元音 | 元音段落内部做一次共振峰滑动（`F` → `F2`，转折点 `DIPH_AT`≈0.45）|
| 近音 `r w j` | 稳态共振峰 + 滑向元音；`r` 的 F3 压到 1600Hz 是它最硬的听感线索 |
| 塞擦音 `tS dZ` | 闭塞 + 起爆 + 咝音摩擦 |
| 浊擦音 `v D z Z` 与浊塞音 | 噪声段上再叠浊音成分（`voicing`）—— 浊擦音是「声带振动 + 摩擦」并存，纯噪声听上去就是清擦音 |

`/S/`（sh）与 `/s/` **必须用两套谱形**：`s` 走 3.4kHz 高通 + 4.8/6.8/8.8kHz 峰
（质心实测 6227Hz），`S` 走 2.0kHz 高通 + 2.6/3.8/5.4kHz 峰（质心 3286Hz）。
共用一套的话两者根本分不开。

### 英语与中文的 VC 规则不同

中文 CVVC 里不送气塞音在 VC 段要换成送气音（b→p、d→t、g→k），因为 VC 不含成阻。
**英语不能这么做** —— 英语的清浊塞音是真实的音位对立（`bag` vs `back`），
所以 `vc_initials()` 在英语里返回全部辅音。

## 运行

从**项目根目录**运行（脚本里的 `out/`、`demo/`、`ref/` 都是相对当前目录的）：

```
python src/build.py                    # 中文声库（默认 D#4）
python src/build_english.py            # 英语声库（Delta 式 CVVC）
python src/build.py --pitch C4 C5      # 多音阶
python src/build.py --only vowels cv   # 只做一部分（注意：会清掉旧采样）
python src/dsp.py                      # 声源数学自检
```

实验脚本（结果写到 `demo/`）：

```
python src/experiments/compare_sources.py   # 三种声源方案对比
python src/experiments/s_variants.py        # /s/ 方案对比
python src/experiments/timbre_variants.py   # 并联共振峰幅度曲线对比
python src/experiments/timbre2_variants.py  # 高频配比对比
python src/experiments/calibrate.py         # 用参考声库反解共振峰增益
```

工具（`tools/`）：`extract_sjis.py` 解压 Shift-JIS 文件名、`mf.py` 下 MediaFire、
`links.py` 从网页挑下载链接、`local_recv.py` 浏览器取到的文件转存到本地。

依赖：Python 3.11 + numpy + scipy。写 WAV 用标准库 `wave`，无需 soundfile。
