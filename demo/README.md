# demo 索引

每次调音色都会渲一组对照样本供试听挑选。这里按**主题**编号，同一主题下的
变体统一用 `01_ / 02_ / …` 命名。

**这个目录可以随时整个删掉**——每一组都能用 `src/experiments/` 里对应的脚本
重新生成。真正生效的参数在 `src/config.py` 和 `src/phonemes.py` 里。

## 试听样本前后都补了静音

`_demo.py` 的 `write()` 会在**开头和结尾各补 100ms** 静音。爆破音的起音是
紧贴第 0 采样的瞬态，播放器一开声就碰上硬边、尾巴还会被截断；补上之后可以直接
用普通媒体播放器逐条点开。**声库本身（`out/`）不补**，那是给 UTAU 用的。

## 命名约定

- 顶层 `NN_主题`，`NN` 决定试听顺序，`00_` 表示已废弃但仍想留档的实验
- 变体 `NN_简短描述`，同一主题内编号唯一
- 需要保留的旧结论写进本表，不要靠目录名记忆

## 每个脚本运行前会清空自己的输出目录

`src/experiments/_demo.py` 提供 `fresh(OUT)`，所有实验脚本在 `main()` 开头调用。
**历史教训**：脚本只写不删的话，改了变体名之后旧变体仍留在磁盘上，会出现
新旧两套并存的局面（`demo/09_噪声源` 就这么同时存在过 `02_倾斜6` 和
`02_声源派生`）。
